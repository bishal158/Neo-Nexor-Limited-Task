## 1. Assignment Overview

This assignment assesses the candidate’s ability to translate a website requirement into a clean, responsive, visually engaging, and maintainable frontend application.

The evaluation will focus on:
- UI/UX design sense
- Frontend implementation
- Visual presentation
- Usability
- Responsive behavior
- Component reusability
- Code quality

## 2. Project Brief

Build a modern, elegant, and responsive **Interior Design Company Portfolio Website** for a professional interior design studio. The website should showcase the company’s design expertise, completed projects, services, design approach, and company information.

The overall design should feel **premium, minimal, professional, and visually focused**, with strong use of interior and project imagery.

## 6. UI / Design Expectations

The website should have a strong visual identity suitable for a professional interior design company.

- Clean, modern, and elegant interface
- Premium visual appearance
- Clear visual hierarchy
- Strong typography
- Consistent spacing and alignment
- Balanced color combination
- High-quality project image presentation
- Well-designed project cards
- Professional buttons and CTAs
- Consistent section structure
- Proper use of whitespace
- Subtle and meaningful animations / interactions
- Avoid unnecessary decorative elements
- **The design should prioritize visual storytelling through interior design images.**
